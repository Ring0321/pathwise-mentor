# 03 源码与上云部署说明

## 工程路径

`../sepath-cloud-app/`

`../sepath-sites-app/`

其中：

- `sepath-cloud-app/` 是本地演示与静态部署版，适合录屏、离线评审、Docker/Nginx 或任意静态托管。
- `sepath-sites-app/` 是 OpenAI Sites / Cloudflare Worker 兼容云部署版，适合证明项目具备上云、版本化发布、访问控制和生产 URL 能力。

## 技术栈

- React 19
- TypeScript
- Vite
- Vitest
- lucide-react
- Nginx Docker 静态部署配置
- vinext / OpenAI Sites / Cloudflare Worker 云部署配置
- Postgres/Supabase 数据平面 SQL 草案、RLS 和索引说明

## 本地运行

```bash
cd sepath-cloud-app

npm run dev
```

当前产品模块：

- 学生闭环：失败 PR、CI 证据、能力画像、路径数字孪生。
- 仓库证据接入：Issue、PR、CI、Review 和反思样本可归一化为 EvidenceEvent。
- 班级 GrowthOps：将单个学生闭环升级为班级风险分层、干预队列和飞书同步预览。
- 策略实验室：同事件回放普通聊天、固定路径和 SE-Path SafeVOI 闭环，解释为什么当前策略更优。
- 课程配置：把课程目标、Rubric、软件工程作业模板、AI 使用边界和课程 Manifest 做成可迁移配置。
- 学生对话：把自然语言求助转为意图识别、风险判断、脚手架回复和 EvidenceEvent 写回。
- 教师周报：把学生阻塞、班级信号、下周行动、AI 边界和证据引用导出为 Markdown。
- 课程试点：把班级接入、数据治理、教师确认、试点指标和分阶段上线门禁做成产品内工作台。
- 隐私治理：角色最小权限、数据分级、敏感字段扫描和越权请求拦截进入产品内发布门。
- API 契约：真实 Git/CI/LMS/飞书接入 API、Webhook、幂等键、环境变量和租户隔离进入产品内契约。
- 集成回放：Git、CI、LMS、飞书 Webhook 样例可在产品内完成脱敏、幂等、契约匹配和 EvidenceEvent 写回。
- 学习增值评估：把能力增量、SafeVOI 策略优势、风险拦截、教师工时、科研边界和真实试点 Telemetry Contract 做成可解释价值模型。
- AI Agent 运行时：把确定性策略内核、可选 LLM 表达层、GraphRAG 上下文包、工具 Trace、质量门和无 Key 降级做成可上线模型接入中心。
- 生产数据平面：把 Postgres/Supabase 表结构、RLS、索引、备份恢复、健康探针和环境变量边界做成产品内运维证据。
- 课程开班向导：把课程配置、工具接入、教师复核、评委试用和 AI 运行时整理成 D-7 到 W1 的首周落地清单。
- 模型治理：SafeVOI、路径数字孪生、知识边界、实验协议、发布门和漂移监控进入产品内 ModelOps 看板。
- Agent 决策台：诊断、SafeVOI 排序、脚手架提示。
- 课程知识边界：Rubric、代码证据、AI 使用策略和反思记忆的可审计检索面板。
- 算法验证与科研证据：以消融对照、合成样本回放和试点边界说明智能性来源。
- 参赛评审证据：将官方评分项、实现模块和提交材料映射到可审计证据表。
- 主张证据账本：把参赛主张按 L0/L1/L2/L3 证据层级绑定到材料、脚本、截图和运行时模块，避免过度宣称。
- 上线试用与交付就绪：将健康检查、云端访问、监控指标、回滚策略和人工门禁展示为产品内证据面板。
- 教师复核台：高风险建议进入人工发布门。
- 证据交付：手动补证据、复制摘要、导出证据账本，并可导入 JSON 账本恢复工作空间。

### 静态托管

执行 `npm run build` 后，将 `dist/` 目录部署到 Vercel、Netlify、Cloudflare Pages、OpenAI Sites 或任意静态站点服务；也可以直接上传 `参赛提交材料包/公开试用静态包/`。

### Docker/Nginx

```bash
docker build -t sepath-cloud-app .
docker run -p 8080:80 sepath-cloud-app
```

或使用 Compose：

```bash
docker compose up --build
```

标准化部署配置可通过 `rtk python scripts/validate_deploy_artifacts.py --write` 复核，报告输出到 `sepath-cloud-app/qa/deploy-artifacts-validation.json` 和 `参赛提交材料包/72_标准化部署配置与容器化验收说明.md`。

### 后端增强

当前闭环算法在前端纯函数中运行。后续正式上线时建议拆分：

- `src/engine/diagnosis.ts` -> 诊断 API 服务。
- `src/engine/safeVoi.ts` -> 策略服务。
- `src/engine/reviewGate.ts` -> 发布门与教师复核服务。
- `src/engine/demoOrchestrator.ts` -> 事件总线与状态回放服务。
- localStorage -> Supabase/Postgres/学校课程平台数据库。
