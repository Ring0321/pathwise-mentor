# SE-Path 学伴参赛提交材料总览

本目录用于汇总“AI 开发者大赛 / AI 应用赛 / 自适应学习伙伴智能体”方向的正式提交材料。当前项目主线是：面向软件工程项目式学习，构建一个可运行、可验证、可上云的闭环伴学系统。

## 官方要求拆解

根据比赛页面截图，本赛题要求设计并实现面向特定学科专业的“自适应学习伙伴智能体”，至少覆盖：

- 学情诊断：通过对话或测试动态分析学生知识掌握情况，构建学生画像。
- 路径规划：基于学生画像与知识图谱，动态生成个性化学习路径。
- 实时干预：学生遇到困难时，提供针对性脚手架式辅导，而不是直接给答案。
- 记忆与反思：智能体具备长期记忆能力，能在多次交互中持续优化学习计划。

截图中的提交要求包括：

- 项目计划书，文档命名为“队伍名+作品名”。
- 源代码或可运行演示 Demo。
- 3-5 分钟演示视频，展示智能体与学生交互等过程。
- PDF 或 PPT 格式提交，单文件 100MB 以内；多个文件应压缩为一个 ZIP。
- 可选补充实物产品、演示 Demo、视频、图片等材料。
