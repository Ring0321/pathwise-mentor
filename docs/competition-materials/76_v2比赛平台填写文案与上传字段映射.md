## 4. 300 字作品摘要

SE-Path 学伴是面向软件工程项目式学习的自适应学习伙伴智能体。系统不把学生困难简化为一次聊天问答，而是从 PR 失败、CI 日志、测试覆盖、Review 意见、学生求助、教师复核和反思中采集 EvidenceEvent 证据，形成学生能力画像和增值诊断单。诊断单展示当前水平、期望水平、差值、证据覆盖率和不确定性；证据不足时显示待补证，不强行给结论。

在路径干预上，系统使用 Safe-VOI 策略，从学习价值、风险、可逆性、证据覆盖和教师负担等维度选择下一步行动。学生直接索要完整代码时，系统触发安全门禁，只给检查清单、失败用例模板和脚手架提示，不替学生完成可提交答案。教师在 Vue3 + Element Plus + 芋道风格工作台中完成批准、退回补证据或转人工会谈，学生完成修复和反思后，系统写入证据账本并更新学习路径。当前 v2 Demo 已跑通工单队列、增值诊断、Safe-VOI、教师复核、学生回流、Rubric 配置和 JSON 账本导出。

## 5. 500 字作品介绍

SE-Path 学伴定位为“软件工程项目式学习的证据驱动学习闭环工作台”。在软件工程课程中，学生真正的困难往往出现在工程过程里：不会定位 CI 失败、不会补足边界测试、不会解释 PR 变更、不会根据 Review 修复，也不会把一次失败迁移成下一次改进。普通 AI 答疑容易给出即时答案，却难以留下可复核的成长证据，甚至可能替学生完成代码。

本作品把软件工程学习过程建模为 EvidenceEvent 证据账本。PR、CI、Review、学生对话、教师复核和反思都进入同一条证据链，系统据此生成增值诊断单：不仅给出当前能力，还显示期望能力、差值、证据覆盖和不确定性。这样，评价不再是一次性分数或排名，而是服务于形成性诊断和下一步资源匹配。

在干预策略上，SE-Path 使用 Safe-VOI 选择安全下一步。系统优先提供低风险、可复核、能促进学习的脚手架，例如异常路径检查清单、最小失败用例模板、测试补全建议和反思提示。当证据不足或学生请求完整答案时，系统不会自动发布结论，而是进入教师复核。教师可以批准脚手架、退回补证据或转人工会谈，最终发布权保留在教师侧。

当前 v2 Demo 已做成 Vue3 + Element Plus + 芋道风格教师工作台，支持课程工单队列、学生增值诊断单、Safe-VOI 建议、教师复核面板、学生回流、Rubric 配置、证据账本抽屉和 JSON 导出。它不是一个静态展示页，而是能把一次失败 PR 转成诊断、干预、复核、补证据、反思和增值更新的完整闭环原型。

## 6. 创新点填写

1. **证据原生**：从 PR、CI、Review、对话、反思和教师复核形成 EvidenceEvent，而不是只看一次问答。
2. **增值评价核心化**：用起点、当前、期望、差值、证据覆盖和不确定性做形成性诊断，不做排名惩罚。
3. **Safe-VOI 干预**：下一步建议同时考虑学习价值、风险、可逆性、证据覆盖和教师负担。
4. **教师发布门**：AI 只给候选建议，教师决定批准、补证据或转人工会谈。
5. **不替写安全边界**：学生索要完整代码时，只给脚手架、检查清单和失败用例模板。
6. **学生回流闭环**：学生完成补证据和反思后，系统写入账本并更新路径状态。
7. **Rubric 可配置**：课程目标、能力图谱、证据来源和低证据边界可在工作台配置。
8. **芋道化落地**：按管理台工作台形态组织工单、复核、账本和课程配置，后续可接 RBAC、多租户和数据权限。

## 7. 技术路线填写

前端采用 Vue3、TypeScript、Vite、Element Plus 和芋道风格管理台布局，实现教师工作台和学生回流闭环。核心数据对象包括 `LearningWorkOrder`、`EvidenceEvent`、`SafeVoiRecommendation`、`TeacherReviewDecision`、`ValueAddedDimension` 和证据账本条目。第一版使用本地 mock API 与本地状态跑通闭环，后续可迁移到芋道后端、Spring Boot、RBAC、多租户、数据权限和学校身份体系。

流程上，系统先从 PR/CI 失败或学生求助生成学习工单，再汇聚 Git、CI、Review、对话、反思等证据，形成增值诊断单。Safe-VOI 策略选择下一步脚手架建议，教师在工作台复核后发布。学生完成修复、补证据和反思后，系统写入证据账本并更新路径阶段。Demo 已包含流程测试、构建产物、响应式截图、证据账本样例和提交包清单。

## 8. 应用场景填写

1. **高校软件工程课程**：辅助教师处理 PR/CI 失败、测试覆盖不足、Review 反馈和学生反思。
2. **高职与产教融合项目课**：把项目过程证据转化为学习支持和教师复核工单。
3. **企业新人训练营**：围绕真实开发任务训练异常处理、测试补全、协作表达和复盘迁移。
4. **AI 编程素养课程**：规范学生使用 AI 的边界，避免直接答案替代学习过程。

## 9. 商业价值填写

SE-Path 的价值不是卖聊天次数，而是提升项目式课程的过程管理能力。对高校教师，它能把分散在 Git、CI、Review 和对话中的学生困难转成可处理工单；对学生，它能把一次失败转成下一步可执行行动；对学院或产教融合项目，它能沉淀可追溯证据账本，用于课程改进和试点复盘。商业化可从课程试点服务、学生席位、学院版私有化部署和企业训练营配置切入，但真实效果需要在授权、脱敏、教师标注和试点验证后再声明。

## 12. 真实性与边界声明

当前 v2 Demo 使用本地 mock API 和本地状态证明产品闭环，不宣称已接入真实学校生产数据。增值评价只做形成性诊断和学习支持，不做排名、不做惩罚、不做就业预测。AI 只生成候选建议，最终发布、评价和高风险判断均由教师确认。证据不足时，系统显示不确定或待补证，不强行给结论。
