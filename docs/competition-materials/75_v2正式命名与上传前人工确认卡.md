## 4. 一键生成正式命名包

填写完成后运行：

```powershell
python -X utf8 scripts/prepare_v2_final_named_submission.py --profile submission/v2_final_submission_profile.filled.json
```

若已经生成过同名目录，需要覆盖本轮生成结果时运行：

```powershell
python -X utf8 scripts/prepare_v2_final_named_submission.py --profile submission/v2_final_submission_profile.filled.json --force
```

脚本会输出：

- 正式命名目录：`submission/v2_final_named/队伍名+作品名_正式提交包/`
- 正式 ZIP：`submission/队伍名+作品名_正式提交包_2026-08-24.zip`
- SHA256 校验值
- 包内文件数量

## 5. 阻断规则

脚本在以下情况下不会生成正式包：

- 队伍名仍包含“待填写”。
- 队员姓名、学校、专业、角色仍未填写。
- 关键确认项没有全部改为 `true`。
- 声称已接真实课程数据，但没有提供试点证据。
- 需要公网 URL，但 `final_public_url` 为空。

这些阻断是为了避免误传半成品，也避免把未经验证的效果或敏感信息写入正式材料。
